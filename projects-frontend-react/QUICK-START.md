# Quick Start Guide

## 🎯 First Time on This Computer?

Run this ONE command:

```bash
./setup-local-env.sh && npm install && npm run dev
```

That's it! The script will auto-configure everything.

---

## 🔄 Already Set Up? Just Run:

```bash
npm run dev
```

---

## 📍 Where to Access:

- **React App**: Check terminal output for `http://localhost:XXXX/`
- **WordPress**: http://localhost:MAMP_PORT/sabarajendran/

Your ports are saved in `.env.development` (not synced to Git).

---

## 🆘 Having Issues?

1. Make sure MAMP is running
2. Re-run: `./setup-local-env.sh`
3. Read: `LOCAL-SETUP-GUIDE.md` for details
