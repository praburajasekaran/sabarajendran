## How to Use the Slide Deck

### Option 1: Browser Presentation
1. Open `/docs/campaign-slides.html` in Chrome, Firefox, or Safari
2. Press `F11` for fullscreen mode
3. Use `Page Down` or scroll to navigate slides
4. Press `Cmd+P` to print/export to PDF

### Option 2: Export to PDF
1. Open `campaign-slides.html` in Chrome
2. Press `Cmd+P` (Mac) or `Ctrl+P` (Windows)
3. Select "Save as PDF" as destination
4. Choose "Landscape" orientation
5. Set margins to "None"
6. Enable "Background graphics"
7. Click "Save"

### Option 3: Copy to Google Slides/PowerPoint
1. Open the Markdown version: `CAMPAIGN-SLIDE-DECK.md`
2. Copy content slide by slide
3. Paste into Google Slides or PowerPoint
4. Apply DMK branding colors from the branding guide
