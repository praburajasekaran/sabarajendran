## PHASE 2 - ADDITIONAL REQUIREMENTS (New Scope)

**Based on client meeting held on December 2, 2025**

Following our discussion, the client has requested the following additional features to enhance the constituency portal. These requirements are in addition to the Phase 1 approved scope.

### DEVELOPMENT SCOPE

| # | Feature | Description |
|---|---------|-------------|
| **1** | **Featured Projects Carousel** | 10-15 featured projects slider on homepage with images and copy. Managed via WordPress backend with auto-sync to React frontend. Touch/swipe gestures, responsive design. |
| **2** | **Three Block Cards Section** | Homepage section with three cards representing NLC, Panruti, and Kurunji Padi blocks. Shows project counts. Click-to-filter functionality. |
| **3** | **Block Filter (Projects Page)** | Add "Block" filter to existing projects page filter panel. Three options: NLC, Panruti, Kurunji Padi. WordPress taxonomy integration. |
| **4a** | **Translation System using ChatGPT API** | Integration with Claude AI for automated Tamil ↔ English translation. |
| **4b** | **Bilingual Architecture** | Complete bilingual content model in WordPress. Language switcher UI. Support for both English and Tamil content throughout the site. |
| **4c** | **Data Entry Scripts** | Automated scripts to extract data from 11 Kurunji Padi block PDF files (Tamil content) and import into WordPress with translation. |
| **5** | **Social Media Feeds Widget** | Elfsight widget integration for Facebook, Instagram, and X (Twitter) feeds. Real-time updates, responsive embed, branded styling. |
| **5a** | **Elfsight Annual Subscription** | First-year subscription included (3 widgets, 5,000 views/month). BFCM annual plan at $9/month. |
| **6** | **WhatsApp Image Generator** ⭐ | Dynamic WhatsApp-shareable image generator (1080x1080px). Creates downloadable graphics with top 5-10 projects at both Panchayat and Village levels. Includes MLA photo, branding, Tamil text support. Download & Web Share API integration. |
| **7** | **MLA Welcome Video** | Embed welcome video from MLA on homepage. Professional video player with controls, lazy loading, responsive sizing. |
| **8** | **Video Bytes Throughout Site** | Video content management system in WordPress. Reusable video components with lightbox/modal player. Strategic placement across pages. Admin UI for video management. |
| **9** | **Key Projects Page** | Dedicated page showcasing 10 major/flagship projects. Large images, titles, descriptions. Curated selection with admin interface. SEO optimized. |
| **10** | **Integration & Testing** | Cross-feature integration testing, WordPress data model updates, filter system enhancements, performance testing, cross-browser verification, mobile responsiveness checks, final QA. |
